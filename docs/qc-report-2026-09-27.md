## Black-box API testing (in-memory store, dev auth)

Auth failures, every validation branch, CORS, 60+ SSRF spellings (decimal/octal/hex
IPs, IPv6 literals and mapped forms, `localtest.me`, `nip.io`, redirects to
127.0.0.1 and 169.254.169.254), limits, duplicates, withdraw, and two real
iptv-org playlists (82 and 17,598 channels) through `/api/playlists/verify`.
