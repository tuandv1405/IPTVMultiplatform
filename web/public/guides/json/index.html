Danh sách phát JSON

TS IPTV đọc được hai dạng danh sách kênh JSON: JSON chung (dạng riêng của TS IPTV, rất linh hoạt) và dạng streams.json của iptv-org. Trang này mô tả cả hai.

TS IPTV không có sẵn kênh nào. Ứng dụng chỉ phát các danh sách phát do bạn thêm vào. Trang này chỉ mô tả định dạng, không giới thiệu danh sách nào.

Hai dạng JSON

JSON không có một chuẩn chung cho danh sách kênh; mỗi ứng dụng dùng một dạng riêng. TS IPTV đọc hai dạng:

  • JSON chung: một đối tượng hoặc mảng chứa các kênh (và có thể có nhóm). Tên trường có vài biến thể được chấp nhận, nên nhiều tệp JSON tự tạo đọc được ngay.
  • Dạng streams.json của iptv-org: một mảng luồng, mỗi phần tử có channel, title, url và header. Dự án iptv-org dùng dạng này cho dữ liệu công khai của họ.

TS IPTV tự nhận ra dạng: nếu tệp bắt đầu bằng [ và phần tử đầu tiên có channel, url, title mà không có name, đó là dạng iptv-org; mọi tệp khác bắt đầu bằng { hoặc [ là JSON chung.

Cú pháp

JSON chung

Các dạng cấp cao nhất được chấp nhận:

  1. một đối tượng { "name", "epgUrl", "channels": [ … ], "groups": [ … ] } (cũng chấp nhận channel và group);
  2. một đối tượng chỉ có channels, hoặc chỉ có groups;
  3. một mảng các đối tượng kênh: [ { … }, { … } ];
  4. một mảng các đối tượng nhóm.

Trường không có trong bảng sẽ bị bỏ qua.

Ví dụ đầy đủ

JSON chung

Kênh đầu tiên là luồng thử nghiệm công khai của Mux (Big Buck Bunny © Blender Foundation, CC BY 3.0); các kênh khác dùng đường dẫn giả example.com.

Tải playlist.json
{
  "name": "TS IPTV example playlist",
  "epgUrl": "https://tsiptv-8bdd6.web.app/examples/guide.xml",
  "channels": [
    {
      "id": "HlsTest.example",
      "name": "HLS Test Channel",
      "url": "https://test-streams.mux.dev/x36xhzz/x36xhzz.m3u8",
      "group": "Test",
      "epgId": "HlsTest.example"
    },
    {
      "id": "ExampleRadio.us",
      "name": "Example Radio",
      "url": "https://cdn.example.com/radio/stream.aac",
      "group": "Radio"
    }
  ],
  "groups": [
    {
      "name": "News",
      "channels": [
        {
          "id": "ExampleNews.us",
          "name": "Example News",
          "url": "https://cdn.example.com/news/index.m3u8",
          "logo": "https://example.com/logos/news.png",
          "epgId": "ExampleNews.us",
          "attributes": {
            "user-agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64)",
            "referrer": "https://example.com/"
          }
        }
      ]
    }
  ]
}
  1. name và epgUrl: tên danh sách và lịch phát sóng ví dụ.
  2. channels: hai kênh tự khai báo nhóm bằng group (“Test” và “Radio”).
  3. groups: nhóm “News” chứa một kênh có logo, epgId và hai header trong attributes.

Dạng ngắn nhất là một mảng: [{"id":"a","name":"A","url":"https://cdn.example.com/a.m3u8"}].

Phần tử thứ nhất là luồng thử nghiệm của Mux, không có header. Phần tử thứ hai là một đường dẫn giả, có feed, referrer và user_agent; mã luồng của nó là ExampleNews.us@HD.

Tự viết một tệp

  1. Mở một trình soạn thảo văn bản thuần. VS Code tốt nhất vì nó báo lỗi cú pháp JSON ngay khi gõ.
  2. Chép một trong hai ví dụ ở trên và sửa các kênh.
  3. Dùng nháy kép thẳng " cho mọi khoá và chuỗi; id luôn là chuỗi ("7", không phải 7).
  4. Không để dấu phẩy sau phần tử cuối cùng và không viết chú thích //.
  5. Lưu với mã hoá UTF-8 (không BOM), đuôi .json.

Cần header cho từng kênh, DRM hay thông tin xem lại? Hãy dùng M3U hoặc TS IPTV Source. Cần phim lẻ, phim bộ có mùa và tập, nhiều luồng cho mỗi mục, hoặc bố cục trang chủ và màu sắc riêng? Hãy dùng TS IPTV Source, cũng là một định dạng JSON.

Đưa tệp lên mạng

Giống như M3U: mọi đường dẫn HTTPS trả về chính nội dung tệp đều dùng được (https://raw.githubusercontent.com/<user>/<repo>/<branch>/playlist.json, https://<user>.github.io/<repo>/playlist.json, https://www.example.com/playlist.json, Dropbox với dl=1). Trang hiển thị tệp trên GitHub (github.com/…/blob/…) là trang web, không phải tệp. Máy chủ nên gửi Content-Type: application/json, nhưng TS IPTV tự nhận dạng nội dung. HTTPS được khuyến nghị; TS IPTV không cần CORS. Chi tiết: đưa tệp M3U lên mạng.

Thêm vào TS IPTV

  1. Mở Thêm nguồn IPTV (nút Thêm IPTV).
  2. Nhập Tên nguồn, dán đường dẫn vào Liên kết nguồn rồi chọn Thêm IPTV; hoặc chọn Nhập từ tệp và chọn tệp .json.
  3. TS IPTV nhận ra dạng JSON và cho biết số kênh tìm thấy. Nếu tệp có epgUrl, lịch phát sóng được tải cùng lúc.

JSON playlists

TS IPTV reads two JSON channel-list shapes: generic JSON (TS IPTV's own, flexible shape) and the iptv-org streams.json shape. This page describes both.

TS IPTV includes no channels. It plays only the playlists you add. This page describes formats only and recommends no list.

Two JSON shapes

There is no common standard for JSON channel lists; every app uses its own shape. TS IPTV reads two:

  • Generic JSON: an object or array of channels (optionally in groups). Several field-name variants are accepted, so many home-made JSON files read as they are.
  • The iptv-org streams.json shape: an array of streams, each with channel, title, url and headers. The iptv-org project uses this shape for its public data.

TS IPTV detects the shape: if the file starts with [ and the first element has channel, url and title but no name, it is the iptv-org shape; any other file that starts with { or [ is generic JSON.

Syntax

Generic JSON

Accepted top-level shapes:

  1. an object { "name", "epgUrl", "channels": [ … ], "groups": [ … ] } (channel and group are accepted too);
  2. an object with only channels, or only groups;
  3. an array of channel objects: [ { … }, { … } ];
  4. an array of group objects.
Playlist fieldRequiredMeaning
namenoPlaylist name.
epgUrlnoXMLTV guide URL.
channels (or channel)noArray of channels that are in no group, or that name their own group.
groups (or group)noArray of groups: { "id"?, "name", "channels": [ … ] }.
Channel fieldRequiredAlso acceptedMeaning
idyesUnique id, a string.
nameyesDisplay name.
urlyes (or remote_data.url)remote_data: { "url": "…" }Stream URL.
logoUrlnologo, image: { "url": "…" }Logo.
groupTitlenogroupGroup name (when the channel is not inside a groups entry).
groupIdnoGroup id; derived from the name if missing.
epgIdnoepgThe channel's id in the XMLTV guide (like M3U tvg-id).
descriptionnoDescription.
attributesnoA string map with the same keys as M3U attributes. "user-agent" and "referrer" become HTTP headers.

Fields that are not in the table are ignored.

The iptv-org streams.json shape

An array; each element is one stream:

FieldTypeMeaning
channelstring or nullChannel id, for example ExampleNews.us.
feedstring or nullFeed id, for example HD. The full stream id is channel@feed, for example ExampleNews.us@HD.
titlestringStream title.
urlstringStream URL.
referrerstring or nullReferer header.
user_agentstring or nullUser-Agent header.
qualitystring or nullMaximum quality, for example 720p.
labelsarrayLabels such as Geo-blocked, Not 24/7.

Generic JSON

    },
    {
      "id": "ExampleRadio.us",
      "name": "Example Radio",
      "url": "https://cdn.example.com/radio/stream.aac",
      "group": "Radio"
    }
  ],
  "groups": [
    {
      "name": "News",
      "channels": [

Create one by hand

  1. Open a plain-text editor. VS Code is best because it flags JSON syntax errors as you type.
  2. Copy one of the examples above and edit the channels.
  3. Use straight double quotes " for every key and string; id is always a string ("7", not 7).
  4. No comma after the last element, and no // comments.
  5. Save as UTF-8 (no BOM) with the extension .json.

Need per-channel headers, DRM or catch-up information? Use M3U or TS IPTV Source. Need movies, series with seasons and episodes, several streams per item, or your own home layout and colours? Use TS IPTV Source, which is also JSON.

Host it

Just like M3U: any HTTPS link that returns the file itself works (https://raw.githubusercontent.com/<user>/<repo>/<branch>/playlist.json, https://<user>.github.io/<repo>/playlist.json, https://www.example.com/playlist.json, Dropbox with dl=1). GitHub's file view (github.com/…/blob/…) is a web page, not the file. The server should send Content-Type: application/json, but TS IPTV detects the content anyway. HTTPS is recommended; TS IPTV needs no CORS. Details: hosting an M3U file.

Add it in TS IPTV

  1. Open Add IPTV Source (the Add IPTV button).
  2. Enter a Source Name, paste the link into Source Link and choose Add IPTV; or choose Import from file and pick the .json file.
  3. TS IPTV detects the JSON shape and shows how many channels it found. If the file has an epgUrl, the guide is downloaded with it.
