Format guides

TS IPTV plays what you provide: a playlist, a programme guide, or a link from your provider. Pick the format you have, or the one you want to make yourself.

TS IPTV includes no channels. It plays only the playlists and sources you add. You are responsible for those sources and must be legally entitled to use them.

Each guide shows the real format: the syntax, a complete example file you can download, how to write one by hand, how to host it, how to add it in TS IPTV, and common mistakes.

What is IPTV?

What streams, playlists and programme guides are, how they fit together, and what TS IPTV does.

Playlists

M3U / M3U8

The most common format. A text file: each channel is one description line and one link.

XSPF

An XML playlist, often saved from VLC.

JSON

Channel lists in JSON: the generic shape TS IPTV reads and the iptv-org streams.json shape.

TS IPTV Source

TS IPTV's open format for a whole collection: channels, movies, series, home layout, colours and includes.

Programme guides

XMLTV

An XML file with each channel's schedule, linked to a playlist through tvg-id.
