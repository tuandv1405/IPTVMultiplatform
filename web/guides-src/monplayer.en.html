About MonPlayer's format

TS IPTV includes no channels. It plays only the playlists you add.

  • MonPlayer is a third-party app. The format of its “JSON sources” is not publicly documented: there is no specification on its store listing or its developer's website (checked in September 2026).
  • TS IPTV therefore cannot import that JSON format today. If what you have is an ordinary M3U playlist, add it as an M3U: see the M3U guide.
  • To add support, TS IPTV needs one sample file that you created yourself or are allowed to share, with every stream link replaced by an example.com placeholder, and whether it came from a link or a file. Send it to chintk111999@gmail.com.
  • TS IPTV does not connect to MonPlayer's services or catalogues and will not add them.
