XMLTV programme guides

XMLTV is the most common XML format for electronic programme guides (EPG): it lists channels and each channel's programmes, with start and stop times, titles and descriptions.

TS IPTV includes no channels and no guides. It reads only the playlists and guides you add.

What XMLTV is

XMLTV comes from an open-source project of TV listings tools; the file structure is defined in its official DTD. Today almost every IPTV player reads XMLTV. A playlist says which channels exist; an XMLTV file says what is on them now and next.

Syntax

The root element is <tv>. Inside it, all <channel> elements come first, then the <programme> elements:

<tv>
  <channel id="…">            (zero or more)
    <display-name>…</display-name>
    <icon src="…"/>
  </channel>
  <programme start="…" stop="…" channel="…">   (zero or more)
    <title>…</title>
    <sub-title>…</sub-title>
    <desc>…</desc>
    <category>…</category>
    <episode-num system="…">…</episode-num>
    <rating system="…"><value>…</value></rating>
  </programme>
</tv>

<tv>

The root element. Optional attributes: date, generator-info-name, generator-info-url, source-info-name, source-info-url, source-data-url.

<channel>

Time format

start and stop are YYYYMMDDhhmmss followed by a time-zone offset: 20260927183000 +0700 is 18:30:00 on 27 September 2026 in UTC+7. The DTD says that a time without an offset is UTC, but TS IPTV currently reads such times in the device's time zone. So always write the offset. Intervals are half-open: a programme starts at start and ends just before stop, so one programme's stop should equal the next one's start.

Episode numbers: episode-num

  • system="xmltv_ns": season.episode.part, counted from zero. 2.4. means season 3, episode 5. Each part may be X/Y: 0.11/12.0/2 is season 1, episode 12 of 12, part 1 of 2. Unknown parts are left empty.
  • system="onscreen": free text as shown on screen, for example S03E05. This is the default when system is omitted.

How a guide links to a playlist

  • The URL: an M3U playlist points to its guide with #EXTM3U x-tvg-url="https://…/guide.xml" (or the older url-tvg); a JSON playlist uses the epgUrl field. Several guides may be separated by commas: TS IPTV downloads up to 5 and merges their programmes, dropping duplicates.
  • The channel id: the playlist channel tvg-id="ExampleNews.us" gets the programmes of <channel id="ExampleNews.us">. Copy the id exactly; it is case-sensitive.
  • Time shift: if the guide is off by some hours, add tvg-shift="+1" (in hours) to the channel, or to the #EXTM3U line for every channel.

Create one by hand

Most people do not write XMLTV by hand: the provider gives a guide URL, or the guide is generated by a grabber tool. For a small personal list, writing one is still easy:

  1. Copy the example above into a plain-text editor (Notepad, TextEdit in plain text mode, VS Code).
  2. Add one <channel id="…"> per channel, with an id equal to the playlist's tvg-id.
  3. Add <programme> elements after all the <channel> elements, always with start, stop and a time-zone offset.
  4. Write & as &amp; and < as &lt; in titles and descriptions.
  5. Save as UTF-8 with the extension .xml.
  6. Compress large guides with gzip to guide.xml.gz: gzip -k guide.xml (macOS, Linux), or 7-Zip › Add to archive › format gzip (Windows). Do not use .zip: that is a different format.

Host it

Just like an M3U playlist: any HTTPS link that returns the file itself works, for example https://raw.githubusercontent.com/<user>/<repo>/<branch>/guide.xml.gz, https://<user>.github.io/<repo>/guide.xml or https://www.example.com/guide.xml.gz. Google Drive/OneDrive share pages and GitHub blob/ links do not work. Details: hosting an M3U file.

  • TS IPTV recognises gzip by its content, so it does not matter whether the server sends Content-Type: application/gzip or Content-Encoding: gzip.
  • HTTPS is recommended; CORS is not needed for TS IPTV.
  • Update the file regularly: a guide that only covers past days has nothing to show.

Add it in TS IPTV

  1. Add the guide URL to the first line of your M3U playlist: #EXTM3U x-tvg-url="https://www.example.com/guide.xml.gz" (for JSON: the epgUrl field).
  2. Add that playlist in TS IPTV (or refresh it if it is already there). The guide is downloaded with it.
  3. Open a channel's programme list to see what is on now and next. Use Refresh EPG to download the guide again.

TS IPTV has no separate field for a guide URL yet; the guide always comes with a playlist. If your playlist has no x-tvg-url and you cannot edit it where it is hosted, download the file, add the line above, and use Import from file.

Common mistakes

MistakeSymptomFix
No time-zone offset on start/stopGuide shifted by some hoursAlways add +hhmm. The DTD reads a missing offset as UTC, but TS IPTV currently uses the device's time zone.
channel does not equal <channel id> or tvg-idEmpty guideUse the same string in all three places.
& not written as &amp;XML error, the whole guide is lostWrite &amp;.
<programme> before <channel>Some readers skip the channelsPut all <channel> elements first (DTD order).
Overlapping or duplicate programmesFlickering or repeated rowsMake stop equal the next start.
A gzip file compressed twice, or a .zip“Invalid guide”Compress with gzip exactly once.
The guide only covers past days“No programme guide”Regenerate it daily.
