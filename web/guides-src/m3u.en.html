M3U and M3U8 playlists

M3U is the most common IPTV playlist format: a plain text file where each channel is one description line and one link line. This page gives the full syntax TS IPTV reads, including the Kodi-style attributes.

TS IPTV includes no channels. It plays only the playlists you add. Every example uses example.com placeholders, a public test stream, or TS IPTV's own example files on tsiptv-8bdd6.web.app.

What M3U is

M3U started with the WinPlay3 and Winamp music players as a list of media locations, one per line. The IPTV community extended it into a channel list: each channel gets a name, a logo, a group and an identifier for the programme guide. These extensions are a shared convention, not a formal standard.

NameWhat it is
M3UA plain list of locations, one per line, with no metadata.
Extended M3UThe first line is #EXTM3U, and each entry is preceded by an #EXTINF line.
M3U8The same format encoded as UTF-8. The .m3u8 extension signals UTF-8.

HLS playlists are not IPTV channel lists

HLS streams also use .m3u8 files that start with #EXTM3U (RFC 8216), but those are the index of one stream, not a channel list:

HLS media playlistIPTV channel list
An entry isa 2–10 second segment of one streama channel (a link to that channel's stream)
#EXTINF:<n>segment duration in seconds-1 or 0 (ignored)
Typical tags#EXT-X-TARGETDURATION, #EXT-X-MEDIA-SEQUENCE, #EXT-X-STREAM-INFonly #EXTM3U
Attributes on #EXTINFnonetvg-id="…", group-title="…" and others
Who opens itthe video player, automaticallyyou, when you add a playlist

If you paste the link of an HLS stream into TS IPTV, the app recognises it and asks “This is a single stream”: choose Add as channel to create a playlist with exactly one channel.

Syntax

#EXTM3U [header attributes]
#EXTINF:-1 [key="value" ...],<Channel name>
[#EXTGRP:<group>]
[#EXTVLCOPT:<option>=<value>]
[#KODIPROP:<property>=<value>]
<stream URL>[|Header=Value&Header=Value]

The first line is #EXTM3U. Each channel starts with an #EXTINF line, may have a few option lines, and ends with the link line. Parts in square brackets are optional. Lines that start with # but are not a known tag are comments.

Attributes on the #EXTM3U line

AttributeMeaning
x-tvg-urlXMLTV guide URL. Several URLs may be separated by commas; TS IPTV downloads all of them (up to 5) and merges them.
url-tvgOlder name for x-tvg-url. Read only when x-tvg-url is absent.
tvg-shiftDefault guide time shift in hours (for example +2, -4.5) for channels that do not set their own.
catchup, catchup-days, catchup-source, catchup-correctionDefault catch-up values for channels that do not set their own. See catch-up in the Kodi guide.

Attributes on the #EXTINF line

Each attribute is key="value", with the value in straight double quotes. Attribute names are case-insensitive (tvg-ID is read as tvg-id). All attributes go before the comma; the channel name follows it.

AttributeRequiredMeaning
(name after the comma)yesThe channel's display name: the text after the first comma that is outside quotes, so names may contain commas.
tvg-idrecommendedIdentifier that links the channel to <channel id> in the XMLTV guide. Usually ChannelName.country, for example ExampleNews.us.
tvg-namenoAlternative name used only for guide matching; it does not replace the display name.
tvg-logonoLogo image URL (PNG, JPG or SVG).
group-titlenoThe channel's group. Separate several groups with semicolons: group-title="News;HD" puts the channel in both.
tvg-chno (or ch-number)noChannel number, an integer. Shown before the channel name.
tvg-shiftnoGuide time shift for this channel only, in hours.
radiono"true" marks a radio station: it gets a radio icon and the player shows its logo instead of a video area.
mediano"true" marks an on-demand video instead of a live channel.
catchup, catchup-days, catchup-source, catchup-correctionnoCatch-up information. Stored; playback of past programmes comes later.
user-agent, referrernon-standardSome generators write headers as attributes. TS IPTV reads them, but prefer #EXTVLCOPT or the | suffix below.

#EXTGRP

#EXTGRP:Group name is another way to set a group, and it works two ways:

  • Inside a channel (after #EXTINF, before the link): applies to that channel if it has no group-title.
  • Before channels: becomes the default group for every following channel without a group-title, until an empty #EXTGRP: line or the end of the file.

#EXTVLCOPT

LineMeaning
#EXTVLCOPT:http-user-agent=…User-Agent header for this stream.
#EXTVLCOPT:http-referrer=…Referer header for this stream (note the spelling referrer with two r's; http-referer is accepted too).
other keysStored, no effect.

Headers after |

You can attach HTTP headers right after the link, Kodi style: https://cdn.example.com/live.m3u8|User-Agent=Mozilla%2F5.0&Referer=https%3A%2F%2Fexample.com%2F.

  • TS IPTV splits at the first |: the left part is the stream URL, the right part is Name=Value pairs joined with &.
  • URL-encode the values (/ becomes %2F, : becomes %3A, a space becomes %20). Unencoded values are accepted as long as they contain no &.
  • When the same header is set in several places, the order of priority is: the | suffix, then #EXTVLCOPT, then #KODIPROP, then non-standard attributes.

#KODIPROP

#KODIPROP:key=value lines come from Kodi. They declare the stream type (mimetype), headers and DRM (Widevine, PlayReady, ClearKey). Each key and its platform support is described in the Kodi formats guide.

Part by part:

  1. Line 1: the #EXTM3U header, with x-tvg-url pointing to the example XMLTV guide.
  2. HLS Test Channel: the simplest channel: one #EXTINF line with an id, a number and a group, then the link.
  3. Example News: in two groups (News;HD), with a logo, sending User-Agent and Referer through two #EXTVLCOPT lines.
  4. Example Sports: sends Referer with the | suffix, URL-encoded.
  5. Example Radio: radio="true" marks a radio station.
  6. Example Protected: a Widevine-protected DASH stream, declared with three #KODIPROP lines (see the Kodi guide).
  7. Example Archive: declares shift catch-up for 3 days.

Create one by hand

  1. Open a plain-text editor: Notepad (Windows), TextEdit in plain text mode (macOS) or VS Code. Do not use Word or Google Docs.
  2. Type #EXTM3U on the first line.
  3. For each channel, add two lines: #EXTINF:-1 <attributes>,<Name> and then the stream URL.
  4. Use straight double quotes " around attribute values, not curly quotes “ ”.
  5. Save as UTF-8 (in Notepad: Save as › Encoding: UTF-8; UTF-8 without BOM is best), with the extension .m3u or .m3u8.
  6. Test each stream URL before you share the file, for example in VLC: Media › Open Network Stream.

Host it

Any link that returns the file itself works. The server may send Content-Type audio/x-mpegurl, application/vnd.apple.mpegurl or text/plain; TS IPTV detects the content.

OptionURL shape
GitHub (raw file)https://raw.githubusercontent.com/<user>/<repo>/<branch>/playlist.m3u
GitHub Pageshttps://<user>.github.io/<repo>/playlist.m3u
Any static host (Netlify, Cloudflare Pages, your own nginx…)https://www.example.com/playlist.m3u
DropboxChange dl=0 at the end of the share link to dl=1 so it returns the file, not a preview page.
A file on your deviceNo hosting needed: use Import from file in TS IPTV.

What does not work: Google Drive or OneDrive share pages, Dropbox preview links (dl=0), and GitHub links of the form github.com/<user>/<repo>/blob/…. They return a web page, not the file. Use the Raw or direct-download link instead.

  • HTTPS is recommended. TS IPTV also opens http:// links, but then anyone on the network path can read or change the file.
  • CORS: TS IPTV is an installed app and needs no CORS headers. Add Access-Control-Allow-Origin: * only if web-based players should read the file too.
  • Playlists added by link are downloaded again when you refresh. Keep the URL stable and edit the file in place.

Add it in TS IPTV

On phones, tablets and desktop

  1. Open Add IPTV Source (the Add IPTV button on the home screen).
  2. Enter a Source Name, for example “My channels”.
  3. Paste the link into Source Link and choose Add IPTV. Or choose Import from file and pick an .m3u/.m3u8 file on your device (up to 20 MB).
  4. When the import finishes, TS IPTV shows how many channels it found. If entries were skipped, you also see “N entries could not be imported” and a Details button listing the reasons: a Kodi add-on is needed (plugin://), web-page scraping, or no stream link.

On Android TV

  1. Open the import dialog and use the arrow keys to move between the name, the link and the add button.
  2. Type the link with the on-screen keyboard (or your phone's keyboard, if your TV supports it).
  3. Import from file appears only if the TV has a file picker; most TVs do not, so use a link.

Playlists imported from a file do not refresh on their own: import the file again after you edit it.
