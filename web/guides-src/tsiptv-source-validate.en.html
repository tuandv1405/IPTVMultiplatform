Validate a TS IPTV Source

Paste a TS IPTV Source file or choose one, then press Validate. The check runs entirely in your browser: nothing is uploaded, and the only request this page makes is for the JSON Schema.

TS IPTV includes no channels and no sources. This tool only reads the file you give it. It never opens the links inside it: includes, guides, images and streams are not fetched.

What is checked

  • JSON: the file parses, and its root is an object (E_NOT_JSON). Files over 5 MiB are refused (E_TOO_LARGE). Only uncompressed JSON can be checked here; unzip a .gz file first.
  • Document rules: format is "tsiptv-source", version is 1, and the file has channels, movies, series or includes.
  • The JSON Schema (draft 2020-12): required fields, types, ranges, id and URL patterns, forbidden headers, texts and language keys, and unknown fields, which usually are typos. The schema is stricter than the app, so a file that passes it is almost always accepted (the exceptions are listed in the format guide).
  • Rules the schema cannot express: duplicate ids across channels, movies, series, episodes and includes; duplicate season and episode numbers; include ids starting with epg-; queries that name an unknown include or an xmltv include; ids and banner targets that are not in the file; endYear before year.

Each problem is listed as path — message, for example channels[0].id — must be an id…, with the validation code where the app uses one. Errors are things the schema rejects or TS IPTV drops; warnings are things TS IPTV accepts but handles specially.

What is not checked here

Everything that needs the network or the app: whether links and streams work, the content of includes (M3U playlists, guides, addons, other sources), whether an addon declares a catalogue, colour contrast, and the device's DRM support. TS IPTV checks those when you import the source and lists the results in the preview.
